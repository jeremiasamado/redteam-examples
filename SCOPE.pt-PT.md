# Âmbito e segurança

[EN](./SCOPE.md)

Este repositório contém samples criados de raiz para análise local.

- Usa o material apenas em sistemas e software que te pertençam ou para os
  quais tenhas autorização explícita.
- Não reutilizes a tooling do laboratório contra software ou serviços de terceiros.
- Não publiques credenciais, dados privados, alvos reais ou payloads weaponized.
- O token e os dados do sample são sintéticos e não têm valor fora do laboratório.

O objectivo é demonstrar análise, raciocínio e reporting — não contornar
licenciamento comercial nem obter acesso a sistemas reais.
